## 2. Project Overview & Storytelling

### Tagline
> **Your customers speak. Your AI remembers. Your product improves.**

### Project Description
FeedbackMind AI is an AI-powered product intelligence application that turns scattered customer feedback into persistent, evidence-backed product decisions. It pairs Groq Cloud's ultra-low latency LLM inference with Hindsight Cloud's multi-tenant episodic memory engine (`retain`, `recall`, `reflect`) to eliminate stateless chatbot amnesia and provide product teams with continuous longitudinal context.

### The Problem
1. **Context Window Decay:** Passing months of customer feedback CSVs into ordinary LLM prompts exceeds token budgets, increases latency to tens of seconds, and induces lost-in-the-middle hallucinations.
2. **Stateless LLM Amnesia:** Standard chatbots forget customer history between queries. An LLM asked *"Has dashboard performance improved?"* cannot remember that 3 weeks ago a 16-second latency bottleneck was investigated, or that a fix was deployed in Release 2.4.
3. **Uncited Hallucinations:** Traditional RAG vector databases retrieve loose embeddings without episodic causality, often inventing customer quotes or citing non-existent feedback IDs.

### The Solution
- **Continuous Episodic Retention:** Decomposes incoming customer feedback into atomic memory units (observations, entities, sentiments, and actions) stored in Hindsight Cloud.
- **Contextual Semantic Recall:** Natural-language search retrieves relevant historical memories across multi-month release cycles.
- **Temporal Reflection:** Synthesizes macro shifts in sentiment and emerging friction clusters across disconnected accounts.
- **Evidence-Grounded Citations:** Every strategic insight generated by the AI includes verifiable feedback IDs (e.g., `FB-001`, `FB-013`) tied directly to persistent SQLite database records.

## 4. Hindsight Memory Integration & Core Demonstrations

### 4.1 Memory Architecture (`retain`, `recall`, `reflect`)
- FeedbackMind AI uses `@vectorize-io/hindsight-client` to format raw customer feedback into episodic memory documents containing customer identity, temporal timestamp, source channel, original text, and AI analysis tags.
- Dedicated bank IDs (`feedbackmind-${companyId}`) isolate customer tenants.

### 4.2 Side-by-Side Memory ON / Memory OFF Demonstration
- **Memory OFF (Flat SQLite Records):** 0 Hindsight API calls. Evaluates records as isolated events; cannot correlate past investigations with current release versions.
- **Memory ON (Hindsight Episodic Memory):** Retrieves semantic memories (e.g., 33 units), connects complaints across releases, and delivers verified longitudinal answers citing stored evidence.

### 4.3 Episodic Learning Curve Progression (Checkpoints 1, 5, 20)
| Checkpoint | Retained Interactions | Recalled Units | Cognitive Capability |
|---|:---:|:---:|---|
| **Checkpoint 1** | 1 (`LC-001`) | 6 units | Point-in-time understanding. Single customer latency issue identified with no historical context. Correctly refuses to hallucinate patterns. |
| **Checkpoint 5** | 5 (`LC-001`–`LC-005`) | 22 units | Pattern emergence. Identifies 3 friction categories across navigation, mobile viewport, and search. |
| **Checkpoint 20** | 20 (`LC-001`–`LC-020`) | 33 units | Longitudinal synthesis. Connects release progression from initial bottleneck (16s) to optimization (1.8s) across customer cohorts and identifies the remaining roadmap priority. |

## 6. Disclosures & Boundaries

### 6.1 Security & Deployment Boundary
- **Server-side user authentication is NOT implemented:** The API does not verify user identity via login, JWT, or sessions.
- **Workspace-level authorization / RBAC is NOT implemented:** A caller may potentially access another workspace by supplying its `companyId`.
- **Operational Boundary:** The application is currently suitable **ONLY** for local evaluation, controlled hackathon demonstrations, and restricted internal use. It is **NOT ready for unprotected public multi-tenant SaaS deployment**.
- User authentication and workspace ownership verification must be implemented prior to exposing this service to the public internet.

### 6.2 Synthetic Data Disclosure
- All customer feedback records, customer identifiers (`CUST-001`, `CUST-LC-01`), customer quotes, and learning-curve progression items across `demo-company` and `learning-curve-demo` are **synthetic demonstration test fixtures** created for evaluation and benchmarking without exposing real enterprise customer information.

### 6.3 Test Results Qualification
- The reported 141 passing tests represent **internal project automated test results** executed using Vitest, Supertest, and React Testing Library; they do not constitute third-party external certification.
